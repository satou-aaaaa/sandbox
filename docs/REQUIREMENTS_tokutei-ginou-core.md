# 要件定義書 — 在留資格「特定技能」申請支援モジュール（1号）

version: 0.1 / 2026-09 作成
対象: kensetsu-kyoka-toolkit の拡張（許認可自動化コアの6例目としての実装、事業提案の柱（C）「外国人材関連（中長期）」の第二弾）

## 0. 本書の位置づけ

本書は、事業提案の柱（C）「外国人材関連（中長期）」の第二弾として、在留資格
「特定技能」（1号）のうち、**在留資格認定証明書交付申請（海外から新規に
招へいするケース）のみ**を対象とした要件定義書である。コアの設計は
`docs/DESIGN_kobutsu-core.md`を、第一弾（技人国ビザ）の設計は
`docs/DESIGN_gijinkoku-core.md`・`docs/REQUIREMENTS_gijinkoku-core.md`を
それぞれ参照。開発環境構築・コーディング規約・Git運用は既存の
`docs/DEVELOPMENT_GUIDE.md`を適用する。

**本モジュールは第一弾（技人国ビザ）よりも制度が複雑である
（分野別技能試験・登録支援機関との関係・通算在留期間の上限管理）。
1.3節・6章を特に注意して読むこと。**

## 1. プロジェクト概要

### 1.1 背景

技人国ビザモジュール（`docs/DESIGN_gijinkoku-core.md`）の実装により、
「可変期間の在留資格」というリマインドパターンをコアの`ScheduleFn`契約の
まま拡張できることが実証された。外国人材関連の第二弾として、就労系
在留資格の中でも技人国と並んで件数の多い「特定技能」（1号）を選定する。

特定技能は技人国ビザと異なり、次の3点で制度が大きく異なり、判定・
書類生成のロジックがより複雑になる。

1. 学歴要件ではなく「技能水準」（分野別の技能評価試験に合格しているか、
   または技能実習2号を良好に修了しているか）と「日本語能力水準」
   （日本語能力試験N4以上、またはJFT-Basic合格。技能実習2号修了者は
   原則免除）という、試験合格を軸にした要件になっている
2. 受入れ機関（特定技能所属機関）自体が満たすべき基準（労働関係法令・
   入管法令の遵守実績、報酬水準等）に加え、「1号特定技能外国人支援計画」
   の実施体制（自社で支援基準を満たすか、登録支援機関に委託するか）
   という、技人国ビザには存在しない機関側の審査軸がある
3. 特定産業分野（介護・建設・外食業等、2026年9月時点で19分野）ごとに
   技能評価試験の内容・分野固有の日本語要件（介護分野の介護日本語
   評価試験等）が異なり、また分野ごとに受入れ機関側の追加基準
   （建設分野の建設特定技能受入計画の認定等）が存在する場合がある

技能実習制度そのもの（監理団体の許可・技能実習計画の認定等）、および
特定技能2号（在留期間の更新に上限がなく家族帯同も可能な、より上位の
在留資格）は、いずれも技人国ビザとは別次元の専門性（特定技能2号は
限られた分野のみが対象、技能実習は別の法体系）を要するため、
本フェーズでは対象外とする（4.5節）。

### 1.2 目的

1. 技能水準（分野別技能評価試験合格、または技能実習2号良好修了による
   免除）と日本語能力水準（日本語能力試験・JFT-Basic、または技能実習
   2号修了による免除）の該当性を判定する
2. 受入れ機関（特定技能所属機関）の支援体制（自社支援基準の充足、または
   登録支援機関への委託）の該当性を判定する
3. 在留資格認定証明書交付申請書、および1号特定技能外国人支援計画書の
   記載内容サマリーをdocxで生成する
4. 在留期間の満了リマインドに加え、**通算在留期間（1号は通算5年が
   上限）**の管理・警告リマインドを、可変期間型のリマインドパターンを
   拡張する形でコアのリマインドエンジンに登録する

### 1.3 重要な制約（技人国モジュールとの違いを含む。必読）

- **申請取次行政書士としての届出は技人国モジュールと同じく必須**:
  特定技能の在留資格認定証明書交付申請についても、行政書士が外国人
  本人に代わって出入国在留管理局へ書類を提出する（申請取次）には、
  技人国ビザと同様に地方出入国在留管理局長への届出・研修受講が
  別途必要である。技人国モジュールで確認した届出状況をそのまま
  引き継げるが、対象の在留資格が異なるだけで届出自体を分野ごとに
  やり直す必要はないと考えられる（要最終確認。8章参照）
- **登録支援機関としての登録は、行政書士登録・申請取次の届出とは
  別制度**（技人国モジュールには存在しなかった論点）: 受入れ機関が
  1号特定技能外国人支援計画の実施を外部委託する場合の委託先
  「登録支援機関」は、出入国在留管理庁への別途の登録が必要な法人
  ・個人である。行政書士が登録支援機関を兼ねることは制度上可能だが、
  兼ねるかどうかは発注者（行政書士）の経営判断であり、本ツールキットは
  「登録支援機関としての支援業務の遂行」自体は対象としない。本モジュールが
  対象とするのはあくまで「支援計画の内容が基準を満たしているかの
  一次確認と、支援計画書サマリーの生成」までであり、支援の実施・
  記録管理機能は実装しない（4.5節スコープ外）
- 特定技能は分野ごとに所管省庁・分野別運用要領が異なり、技能評価試験の
  実施団体・試験内容・分野固有の追加要件（介護分野の介護福祉士国家
  試験ルート、建設分野の建設特定技能受入計画認定等）も分野ごとに
  異なる。判定ロジックは「全19分野に共通するコア要件（技能試験or
  技能実習2号修了、日本語試験、受入れ機関基準、支援体制）」のみを
  フェーズ1の対象とし、分野固有の追加要件は9章「今後の拡張ポイント」
  で扱う（4.5節）
- 出入国管理及び難民認定法・特定技能運用要領・分野別運用方針は、
  技人国ビザ以上に改定頻度が高い（分野の追加・受入れ見込み数の
  改定が数年おきに行われている）。本ツールの判定ロジックは
  「申請前の一次スクリーニングに過ぎない」ことを、技人国モジュール
  と同等以上に強調して明示すること。誤った判定は外国人本人の
  在留資格・雇用、および受入れ機関の事業継続に直接影響するため、
  特に慎重な文言設計が必要（技人国モジュールの一次スクリーニング
  注記パターンをそのまま踏襲し、分野固有の留意点を追記する）
- 本システムがどれだけ自動化されても、最終的な書類内容の確認・
  提出（取次）は登録行政書士（申請取次の届出を満たす者）本人が
  行うことが必須であり、これを省略・代替する機能は実装しない
  （既存原則の継承）
- 外国人本人の個人情報（旅券情報・技能試験合格情報・技能実習の
  経歴等）を扱うため、NFR-4（外部送信禁止）を技人国モジュール以上に
  厳格に遵守すること

## 2. 用語集

| 用語 | 説明 |
|---|---|
| 特定技能1号 | 特定産業分野に属する相当程度の知識・経験を要する業務に従事するための在留資格。在留期間は通算5年が上限 |
| 特定技能2号 | 特定技能1号より熟練した技能を要する業務向けの在留資格。対象分野が限定的で、在留期間の更新に上限がなく家族帯同も可能。本フェーズは対象外 |
| 特定産業分野 | 特定技能の受入れが認められる産業分野。2026年9月時点で19分野（介護・ビルクリーニング・リネンサプライ・工業製品製造業・建設・造船舶用工業・自動車整備・航空・宿泊・自動車運送業・鉄道・物流倉庫・農業・漁業・飲食料品製造業・外食業・林業・木材産業・資源循環。e-Gov法令検索の「出入国管理及び難民認定法別表第一の二の表の特定技能の項の下欄に規定する産業上の分野等を定める省令」〈平成三十一年法務省令第六号〉で確認済み） |
| 技能評価試験 | 分野ごとに実施される、業務に必要な技能水準を確認する試験 |
| 日本語能力試験（JLPT） | 一般に特定技能ではN4以上の合格が目安とされる日本語試験 |
| JFT-Basic（国際交流基金日本語基礎テスト） | 日本語能力試験N4相当とされる、生活・就労に必要な日本語能力を測る試験 |
| 技能実習2号の良好な修了 | 技能実習2号を修了した者が、修了時の技能検定等に合格し評価調書等で良好と認められること。同一の作業区分内で特定技能へ移行する場合、技能試験・日本語試験の両方が免除される |
| 特定技能所属機関 | 特定技能外国人を受け入れる企業等（受入れ機関）。労働関係法令の遵守実績・報酬水準等の基準を満たす必要がある |
| 1号特定技能外国人支援計画 | 特定技能所属機関が実施を義務付けられる10項目の支援（事前ガイダンス、生活オリエンテーション、相談対応等）の計画 |
| 登録支援機関 | 1号特定技能外国人支援計画の実施を受入れ機関から委託される、出入国在留管理庁に登録された機関。行政書士登録・申請取次の届出とは別の登録制度 |
| 通算在留期間 | 特定技能1号として在留した期間の合計。5年（切り上げなしで暦月換算）が上限とされ、上限に達すると1号としての在留継続はできない |

## 3. 想定利用者・利用シーン

既存モジュールと同じ利用形態（発注者本人が行政書士登録・申請取次の
届出完了後、CLI/スクリプト操作で使用）。想定シーンとして、企業
（特定技能所属機関）から外国人材の採用に伴う特定技能ビザ手続きの
依頼を受け、①技能水準・日本語能力水準・支援体制の要件判定→
②申請書サマリー・支援計画書サマリーの生成→③在留期間満了・
通算5年上限のリマインド設定、という流れを想定する。技能実習生からの
移行（技能実習2号修了者が国内で在留資格変更する）ケースも将来的な
利用シーンとして想定されるが、本フェーズは新規招へい（認定証明書
交付申請）のみを対象とする（4.5節）。

| FR-T1.4 | 技能水準・日本語能力水準をまとめて総合判定し、未充足理由の一覧を人間可読なテキストレポートに整形できること。判定結果には、技人国モジュールと同等以上に強調した一次スクリーニングの注記を含めること | 1.3節の制約を出力文言レベルで担保する（技人国モジュールの`GIJINKOKU_SCREENING_NOTICE`パターンを踏襲） |

### 4.2 特定技能所属機関の基準・支援体制の判定

| ID | 内容 | 備考 |
|---|---|---|
| FR-T2.1 | 特定技能所属機関が満たすべき基本的な基準（労働関係法令・入管法令違反による処分を過去5年以内に受けていないこと、報酬水準が日本人従業員と同等以上であること等）を判定できること | 号立て・文言は出入国在留管理庁の公表資料（分野横断的な運用要領）で一次資料確認してから確定すること（8章） |
| FR-T2.2 | 1号特定技能外国人支援計画の実施体制について、受入れ機関が自ら支援する場合の基準（支援責任者・支援担当者の選任、外国人が理解できる言語での対応体制、過去2年以内の生活相談業務経験者の配置等）を判定できること | 自社基準を満たさない場合は登録支援機関への全部委託が必須である旨を判定結果に反映すること |
| FR-T2.3 | 登録支援機関への委託の有無（全部委託・一部委託・自社実施）を入力として受け取り、委託先の登録支援機関名を記録できること | 一部委託は自社基準を満たす受入れ機関のみ可能である旨を警告として出せること。登録支援機関としての登録要件自体（委託先が適切に登録されているかの確認）は本ツールの対象外とし、発注者側の確認事項として注記するに留める |
| FR-T2.4 | 支援計画の義務的支援10項目（事前ガイダンス、出入国時の送迎、住居確保等の生活支援、生活オリエンテーション、公的手続への同行、日本語学習機会の提供、相談・苦情対応、日本人との交流促進、転職支援、定期面談）が計画に含まれているかをチェックリスト形式で確認できること | 支援内容の実施そのもの（実施記録の管理等）は対象外。計画書サマリーに記載する項目の網羅性確認に限定する |

### 4.6 スコープ外（本フェーズで対応しないこと）

- **特定技能2号**（本フェーズは1号のみを対象とする）
- **技能実習制度そのもの**（監理団体の許可・技能実習計画の認定・
  技能実習生の受入れに関する判定・書類生成）。技能実習2号の
  「良好な修了」は、あくまで特定技能1号の技能水準・日本語要件の
  免除条件としての入力（自己申告＋添付書類の存在確認）として
  扱うのみで、技能実習側の制度自体の判定は行わない
- 特定技能以外の在留資格（技術・人文知識・国際業務は別モジュール、
  経営管理・家族滞在等）
- 在留資格変更許可申請（既に国内にいる外国人向け。技能実習2号
  からの移行を含む）。本フェーズは新規招へい（認定証明書交付申請）
  のみ対象
- 分野固有の追加要件・追加様式（介護分野の追加的な日本語評価試験
  内容の判定、建設分野の建設特定技能受入計画の認定手続支援等）
- 登録支援機関としての支援業務の実施・実施記録の管理
- 特定技能所属機関・登録支援機関による各種届出（受入れ状況・支援実施
  状況の定期届出等、出入国在留管理局への継続的な届出業務）
- 在留申請オンラインシステムへの電子申請の自動化
- 高度専門職ポイント計算、永住許可・帰化許可申請

### 4.7 非機能要件

既存NFR-1〜7・NFR-C1〜C3、および技人国モジュールのNFR-G1・NFR-G2を継承する。加えて:

| ID | 内容 |
|---|---|
| NFR-T1 | 外国人本人の旅券番号・技能実習時の詳細な処遇記録等、書類生成に不要な個人情報は入力データモデルに含めないこと（NFR-G1の踏襲） |
| NFR-T2 | 判定結果・生成書類のすべての出力に、「一次スクリーニングであり出入国在留管理局・分野所管省庁の個別審査に拠る」旨の文言を含めること（FR-T1.4・FR-T3.4） |
| NFR-T3 | 分野レジストリ（FR-T1.1）は、新しい特定産業分野の追加（過去、分野数が拡大してきた実績あり）に対して、既存分野のコードを変更せずにレジストリへのエントリ追加のみで対応できる構造とすること |

## 5. 受け入れ基準

1. `npm test` が既存分＋新規追加分すべて成功すること
2. 既存モジュール（技人国モジュールを含む）の出力・挙動が変化しないこと（回帰テスト）
3. ダミーデータから技能水準・日本語能力水準・支援体制要件の判定、
   および3種類の出力（認定証明書交付申請書サマリー・支援計画書サマリー・
   添付書類チェックリスト）が生成できること
4. 通算在留期間の起算日を変えて上限到達見込み日を計算した際、正しい
   見込み日が算出されること。また、次回更新候補期限が5年を超える
   ケースで警告が出ること
5. 技能実習2号良好修了による技能試験・日本語試験の免除ケースと、
   試験合格による通常ケースの双方で、要件判定が正しく分岐すること

## 6. 前提条件・依存事項（特に重要）

- **発注者が申請取次の届出・研修を完了していること**（1.3節。技人国
  モジュールと共通の前提条件）
- 出入国在留管理庁・分野所管省庁（厚生労働省・国土交通省・農林水産省等、
  分野により異なる）の公表資料を一次資料として、技能水準・日本語能力
  水準・特定技能所属機関の基準・支援計画の10項目・通算在留期間の
  計算方法を実装前に確定すること
- 特定産業分野の一覧・分野数は改定されうるため、実装直前に
  出入国在留管理庁公式サイトで最新の分野数・分野名を再確認すること
  （本書執筆時点〈2026年9月〉では19分野。**e-Gov法令検索で確認済み・
  2026年9月**: 令和8年〈2026年〉4月1日施行の改正で、従来の16分野から
  林業・木材産業・資源循環の3分野が追加され19分野となった。あわせて
  従来別区分だった一部分野が統合され号番号が振り直されている点にも
  注意）
- 対象様式（在留資格認定証明書交付申請書、1号特定技能外国人支援
  計画書）の最新版を出入国在留管理庁公式サイトから取得すること
  （様式は改定頻度が高いため、実装直前に再確認すること）
- 発注者が登録支援機関を兼ねるかどうか（1.3節）を事前に確認し、
  兼ねる場合でも本ツールキットは支援計画の一次確認・書類生成までを
  対象とする、という役割分担を発注者と合意しておくこと
