# 0010. 財務諸表対応は完成工事原価報告書のみに限定する

Status: Accepted
Date: 2026-09-13

## Context（背景）

ADR-0009・`docs/REQUIREMENTS.md` FR-7.3で保留にしていた財務諸表対応
（貸借対照表・損益計算書・株主資本等変動計算書・注記表。様式第十五号〜
十七号）について調査した。

法人用の財務諸表一式は以下で構成される（[CIIC「建設業財務諸表の解説」](https://www.ciac.jp/kensetuzaimu/hojin/taishaku)で確認済み）。

- **貸借対照表**（様式第十五号）: 流動資産・有形固定資産・無形固定資産・
  投資その他の資産・繰延資産・流動負債・固定負債・純資産の8分類。
  各分類内の勘定科目は「建設業法施行規則別記様式第十五号及び第十六号の
  国土交通大臣の定める勘定科目の分類」（告示）に従う必要があるが、
  この告示の完全な条文（全勘定科目の一覧）を一次資料として取得できなかった
  （PDFの構造上、本ツールの調査環境では本文を読み取れなかった）
- **損益計算書**（様式第十六号）: 売上高・売上原価・総利益／販管費／
  営業外損益／特別損益／法人税等、の5区分。当期純利益は株主資本等
  変動計算書と一致させる必要がある
- **完成工事原価報告書**（様式第十六号の一部）: 材料費・労務費（うち
  労務外注費）・外注費・経費（うち人件費）の**4区分・6項目に固定**されており、
  「勘定科目の追加は認められていません」と明記されている
  （[CIIC「完成工事原価報告書」](https://www.ciac.jp/kensetuzaimu/hojin/kansei)で確認済み）
- **株主資本等変動計算書・注記表**（様式第十七号・十七号の二）: 貸借対照表・
  損益計算書と連動するため、それらが未対応の段階では単独で作成する意味が薄い

貸借対照表・損益計算書は、公式な勘定科目の分類（告示本文）を完全に
把握しないまま実装すると、法定の勘定科目を誤って省略・分類する
リスクがある。これは経審の点数計算を対象外とした理由（ADR-0009）と
同種のリスクである。

一方、完成工事原価報告書は科目が4区分・6項目に完全に固定されており、
複数の信頼できる情報源（登録経営状況分析機関等）で内容が一致している
ため、誤りのリスクが低い。

## Decision（決定）

財務諸表対応（M10）は、**完成工事原価報告書のみ**に限定する。

- 貸借対照表（様式第十五号）、損益計算書本体（様式第十六号のうち
  完成工事原価報告書を除く部分）、株主資本等変動計算書（様式第十七号）、
  注記表（様式第十七号の二）は、国土交通大臣告示の全勘定科目を
  一次資料で確認できるまで対象外とする
- 完成工事原価報告書は、既存の様式生成モジュールと同じ「内容確認用
  サマリー」として実装する。合計金額（完成工事原価）が損益計算書の
  完成工事原価と一致する必要がある旨は注記として明示するに留め、
  損益計算書との整合性チェックは実装しない（損益計算書自体が対象外のため）

## Consequences（影響）

- **メリット**: 誤りのリスクが低い範囲に限定しつつ、決算変更届・経審
  いずれでも必要になる書類の準備を効率化できる
- **デメリット**: 「財務諸表対応」を謳うにはスコープが非常に限定的
  （貸借対照表・損益計算書という財務諸表の中核部分は依然として対象外）
- **見直しのトリガー**: 国土交通大臣告示（勘定科目の分類）の本文を
  入手できた場合、貸借対照表・損益計算書本体の対応を改めて検討する
